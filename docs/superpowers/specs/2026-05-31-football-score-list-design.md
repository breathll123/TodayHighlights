# 今日看点 足球比分列表优化设计

## 目标

优化 `/topics/football` 的足球比分模块，使比赛信息适合实时聚合看板快速扫描。足球模块保留独立展示组件，不复用资讯卡片，避免比分、状态和时间被压缩成通用内容摘要。

本次只调整足球页展示和必要的数据映射，不改变股票、全局看点、后台布局和通用卡片行为。

## 已确认的交互

- 比赛按联赛分组，例如英超、西甲、欧冠。
- 每场比赛使用固定四列：`时间或状态 | 主队 | 比分 | 客队`。
- 模块顶部显示前端最近一次成功获取足球模块数据的时间，格式为 `最近更新 HH:mm:ss`。
- 未开始的比赛显示开赛时间，例如 `20:30`，比分位置显示 `vs`。
- 直播中的比赛优先显示精确分钟，例如 `67'`。数据源没有分钟时，回退显示 `上半场` 或 `下半场`。
- 已结束的比赛显示 `完场`，比分位置显示最终比分。
- 延期、取消和待定状态使用中文文本直接显示。

## 视觉设计

采用紧凑中轴比分表，延续今日看点当前深色信息工作台风格。

### 模块标题栏

- 左侧显示模块标题 `今日赛程与比分`。
- 右侧显示 `最近更新 HH:mm:ss`。
- 使用小字号次级文本，避免更新时间抢占比分视觉层级。

### 联赛分组

- 每个联赛使用独立分组标题。
- 分组标题左侧显示联赛名称，右侧显示场次数量，例如 `3 场`。
- 联赛标题与比赛列表之间使用间距和分隔线建立层级，不增加多余卡片嵌套。

### 比赛行

- 四列布局保持稳定，比分列固定居中。
- 主队和客队允许截断，避免长队名造成横向滚动。
- 比分和时间使用等宽数字样式，减少刷新时的视觉跳动。
- 直播状态使用红色小圆点和文字共同表达，不能只依赖颜色。
- 行项目保留外链能力，点击后在新标签页打开球迷屋比赛详情。
- 提供清晰的 hover 和 focus-visible 状态，支持键盘访问。

### 响应式

- 桌面端和移动端均使用四列布局。
- 移动端缩减横向间距和字号，但保留时间、双方球队与比分。
- 验证 `375px` 和 `1440px` 宽度下无横向溢出。

## 组件边界

### `MatchList`

职责：

- 渲染足球模块标题栏。
- 计算并显示最近成功获取数据的前端时间。
- 按联赛分组比赛。
- 将数字状态转换为中文展示状态。
- 根据比赛状态选择开赛时间、直播分钟、赛段回退或结束文本。
- 渲染紧凑比分行。

输入：

- `data: MatchItem[]`

### `GridRenderer`

职责保持不变：

- 当 `source_type === "qiumiwu_matches"` 时，选择足球专用 `MatchList`。
- 其他来源继续使用原有时间线、列表或通用卡片。

### `StockTopicPage`

职责保持不变：

- 根据路由加载主题元信息和模块数据。
- 将足球页描述中的旧数据源名称从“懂球帝”修正为“球迷屋”。

## 数据映射

后端球迷屋适配器当前返回：

- `league`
- `status`
- `status_name`
- `team_a`
- `team_b`
- `score_a`
- `score_b`
- `start_time`
- `stage`
- `url`

前端按数字状态处理：

| 状态值 | 含义 | 时间列展示 |
| --- | --- | --- |
| `1` | 未开赛 | `HH:mm` |
| `2` | 上半场 | 精确分钟，缺失时显示 `上半场` |
| `8` | 下半场 | 精确分钟，缺失时显示 `下半场` |
| `15` | 完场 | `完场` |
| `18` | 延期 | `延期` |
| `19` | 取消 | `取消` |
| 其他 | 未知或待定 | 优先使用 `status_name`，否则显示 `待定` |

精确分钟字段尚未确认稳定存在。前端应兼容可选的 `minute` 字段；字段为空时使用赛段回退，不阻塞本次交付。

## 更新时间语义

`最近更新 HH:mm:ss` 表示前端 `MatchList` 最近一次成功收到足球模块数据的时间，不表示球迷屋源站内容的发布时间，也不表示后台定时爬虫执行时间。

该时间在 `data` 更新时刷新。组件首次收到数据后立即显示，不需要修改后端接口。

## 错误与空状态

- 页面请求失败继续沿用主题页现有错误提示。
- 足球模块数据为空时继续由 `GridRenderer` 显示 `暂无数据`。
- 单场比赛缺少队名时显示 `待定`。
- 未开赛比赛缺少开赛时间时显示 `待定`。
- 已开始或已结束比赛缺少比分时显示 `-`。

## 测试

为 `MatchList` 增加组件测试，覆盖：

1. 联赛分组与场次数量。
2. 未开赛比赛显示 `HH:mm` 和 `vs`。
3. 直播比赛有分钟时显示分钟。
4. 直播比赛缺少分钟时回退显示 `上半场` 或 `下半场`。
5. 完场比赛显示 `完场` 和最终比分。
6. 标题栏显示格式正确的最近更新时间。

完成实现后运行：

- `npm test`
- `npm run build`
- `git diff --check`

并在浏览器中验证足球页在 `375px` 和 `1440px` 宽度下无横向溢出。
